# FlightGuard
Autopilote de tangage pour avion léger / UAV à voilure fixe, avec surveillance
des pannes capteur, validé automatiquement (cycle en V inspiré de DO-178C).

**Périmètre :** axe de tangage uniquement, 1 capteur, modèle simplifié,
simulation sur PC (aucun matériel réel).

**Outils :** SCADE, C + FreeRTOS, Python, GitHub Actions.
